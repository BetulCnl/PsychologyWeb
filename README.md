# PsychologyWeb

A modern, single-page portfolio website for a psychologist — built with Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion and Lucide React.

## Features

- Editorial hero, about, education, experience, skills, workshops, certificates and contact sections
- Fully responsive, accessible and SEO-optimized
- Content managed through centralized, type-safe data files (`src/data`)
- Contact form powered by a Next.js Route Handler (Resend + Zod validation)

## Getting Started

```bash
npm install
npm run dev
```
